#+title: Package declarations

* Usage
Requires Python 3.11+. Reads =packages.toml= beside the script; override with
=--file PATH=. The profile defaults to =yadm config --get local.class= and must
match a name in =profiles=. Use =--profile NAME= to override it.

#+begin_src sh
./pkgdecl.py check
./pkgdecl.py missing
./pkgdecl.py undeclared
./pkgdecl.py explain PACKAGE
./pkgdecl.py missing --names | xargs -r -o paru -S --needed
#+end_src

=--names= prints package names; =--json= includes details and declaration sources.
Installation and removal are handled by pacman/paru. Undeclared or orphaned
packages are not necessarily unused.

* Commands
| Command       | Purpose                                                        |
|---------------+----------------------------------------------------------------|
| check         | Validate all profiles, or just =--profile NAME=                 |
| list          | Selected declarations; groups expand with =--names=             |
| status        | Explicitly installed packages plus selected declarations       |
| missing       | Declarations not satisfied by installed packages or providers  |
| undeclared    | Undeclared explicit packages; =--all= includes dependencies     |
| dependencies  | Packages installed as dependencies                             |
| orphans       | Dependency-installed packages with no required or optional users |
| installed     | Explicitly installed packages                                  |
| explain NAME  | Package details and declaration sources                        |
| search TEXT   | Search names, descriptions, and sources                         |
| targets       | Mounted files and declaration nodes                            |
| adopt PKG ... | Preview adding explicit packages; =--write= saves               |
| tidy          | Interactively adopt or mark packages as dependencies            |

=adopt= requires =--node PATH= (=.= for root). =--target FILE= selects a mounted
file; =--on MASK= overrides the default current-profile mask. Existing excluded
entries require manual adjustment. Edit generating sources for generated files.
=tidy= shows a preview and asks for confirmation before writing.

* Format
#+begin_src toml
profiles = { personal = 0b100, laboratory = 0b010, laptop = 0b001 }
on = 0b111

[system]
on = 0b110
packages = ["base:111", "linux"]
#+end_src

- Each profile has a distinct bit. Missing =on= inherits; explicit masks replace.
- Package suffixes override node masks. =000= excludes all profiles; selected
  descendants can still be enabled below an excluded parent.
- =groups= lists pacman groups and uses the node mask.
- =directory= mounts another folder's =packages.toml=; relative paths use the
  source file's directory. =optional=true= permits a missing file.
- =depends_on= names nodes in the same file that must already be selected;
  it does not enable them. Cycles are rejected.
